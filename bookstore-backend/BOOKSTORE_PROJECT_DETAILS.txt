Cập nhật: 2026-06-12

================================================================================
1. TỔNG QUAN DỰ ÁN
================================================================================

Tên dự án: Bookstore Backend
Mô tả: Ứng dụng backend cho nền tảng bán sách trực tuyến (e-commerce)
Mục đích: Cung cấp API RESTful để quản lý người dùng, sách, đơn hàng, giỏ hàng
Kiến trúc: Sạch (Clean Architecture) theo nguyên tắc DDD
Phiên bản: 0.0.1-SNAPSHOT
Trạng thái: Đang phát triển

Dự án được xây dựng với mục tiêu:
- Quản lý danh mục sách (categories, authors, publishers)
- Xác thực và phân quyền người dùng (JWT, OAuth2)
- Quản lý giỏ hàng và đặt hàng
- Quản lý tồn kho và nhập hàng
- Hệ thống đánh giá sách
- Mã giảm giá và khuyến mãi
- Quản lý nhà cung cấp
- Thông báo qua email

5. CÁC ENTITIES (ENTITIES CHÍNH)
================================================================================

1. USER (Người dùng)
   - id, email (unique), passwordHash, firstName, lastName, phone
   - status (ACTIVE/INACTIVE/BANNED)
   - roles (nhiều Role)
   - addresses (nhiều UserAddress)
   - createdAt, updatedAt

2. ROLE (Vai trò)
   - id, name (ADMIN, USER, SUPPLIER)
   - permissions (nhiều Permission)

3. PERMISSION (Quyền hạn)
   - id, name (READ_BOOKS, CREATE_ORDER, MANAGE_STOCK, ...)

4. BOOK (Sách)
   - id, title, isbn (unique), price, description
   - author (Author)
   - category (Category)
   - publisher (Publisher)
   - stockQuantity, rating
   - createdAt, updatedAt

5. AUTHOR (Tác giả)
   - id, name, bio, birthDate

6. CATEGORY (Danh mục)
   - id, name, description

7. PUBLISHER (Nhà xuất bản)
   - id, name, address, phone

8. CART (Giỏ hàng)
   - id, user (User)
   - items (nhiều CartItem)
   - createdAt, updatedAt

9. CART_ITEM (Chi tiết giỏ hàng)
   - id, cart (Cart), book (Book), quantity, addedAt

10. ORDER (Đơn hàng)
    - id, user (User), totalAmount, status (PENDING/CONFIRMED/SHIPPED/DELIVERED/CANCELLED)
    - shippingAddress (UserAddress)
    - paymentMethod (CREDIT_CARD/BANK_TRANSFER/COD/WALLET)
    - items (nhiều OrderItem)
    - appliedCoupon (Coupon)
    - createdAt, updatedAt

11. ORDER_ITEM (Chi tiết đơn hàng)
    - id, order (Order), book (Book), quantity, unitPrice

12. REVIEW (Đánh giá sách)
    - id, book (Book), user (User), rating (1-5), comment
    - createdAt, updatedAt

13. COUPON (Mã giảm giá)
    - id, code (unique), discountType (PERCENTAGE/FIXED), discountValue
    - expiryDate, maxUses, currentUses
    - isActive

14. SUPPLIER (Nhà cung cấp)
    - id, name, email, phone, address, status

15. STOCK (Tồn kho)
    - id, book (Book), quantity, lastUpdated

16. STOCK_MOVEMENT (Chuyển động tồn kho)
    - id, book (Book), type (IMPORT/EXPORT/ADJUSTMENT)
    - quantity, reason, createdAt

17. IMPORT_RECEIPT (Phiếu nhập hàng)
    - id, supplier (Supplier), totalItems, importDate
    - items (nhiều ImportReceiptItem)

6. CÁC CONTROLLERS & API ENDPOINTS
================================================================================

1. AuthController - Xác thực
   POST   /api/auth/register              - Đăng ký người dùng mới
   POST   /api/auth/login                 - Đăng nhập
   POST   /api/auth/refresh-token         - Làm mới token
   POST   /api/auth/logout                - Đăng xuất
   POST   /api/auth/verify-otp            - Xác thực OTP
   POST   /api/auth/resend-otp            - Gửi lại OTP
   POST   /api/auth/google-login          - Google OAuth login

2. UserController - Quản lý người dùng
   GET    /api/users/{id}                 - Lấy thông tin người dùng
   PUT    /api/users/{id}                 - Cập nhật profile
   GET    /api/users/{id}/addresses       - Lấy danh sách địa chỉ
   POST   /api/users/{id}/addresses       - Thêm địa chỉ mới
   PUT    /api/users/{id}/addresses/{aid} - Cập nhật địa chỉ
   DELETE /api/users/{id}/addresses/{aid} - Xóa địa chỉ

3. BookController - Quản lý sách
   GET    /api/books                      - Lấy danh sách sách (có phân trang, lọc)
   GET    /api/books/{id}                 - Lấy chi tiết sách
   GET    /api/books/search               - Tìm kiếm sách
   GET    /api/categories                 - Lấy danh mục
   GET    /api/authors                    - Lấy tác giả
   GET    /api/publishers                 - Lấy nhà xuất bản

4. CartController - Quản lý giỏ hàng
   GET    /api/cart                       - Lấy giỏ hàng hiện tại
   POST   /api/cart/items                 - Thêm sách vào giỏ
   PUT    /api/cart/items/{itemId}        - Cập nhật số lượng
   DELETE /api/cart/items/{itemId}        - Xóa sách khỏi giỏ
   POST   /api/cart/coupon                - Áp dụng mã giảm giá
   DELETE /api/cart/coupon                - Hủy mã giảm giá
   POST   /api/cart/checkout              - Tiến hành thanh toán

5. OrderController - Quản lý đơn hàng
   POST   /api/orders                     - Tạo đơn hàng mới
   GET    /api/orders/{id}                - Lấy chi tiết đơn hàng
   GET    /api/orders                     - Lấy danh sách đơn hàng của user
   PUT    /api/orders/{id}/cancel         - Hủy đơn hàng
   GET    /api/orders/{id}/track          - Theo dõi trạng thái

6. ReviewController - Quản lý đánh giá
   GET    /api/books/{bookId}/reviews     - Lấy đánh giá sách
   POST   /api/books/{bookId}/reviews     - Tạo đánh giá
   PUT    /api/reviews/{id}               - Cập nhật đánh giá
   DELETE /api/reviews/{id}               - Xóa đánh giá

7. AdminController - Quản lý hệ thống (cần quyền ADMIN)
   POST   /api/admin/books                - Tạo sách mới
   PUT    /api/admin/books/{id}           - Cập nhật sách
   DELETE /api/admin/books/{id}           - Xóa sách
   POST   /api/admin/stock                - Quản lý tồn kho
   POST   /api/admin/suppliers            - Quản lý nhà cung cấp
   POST   /api/admin/coupons              - Tạo mã giảm giá

8. Các controllers khác:
   - SupplierController
   - StockMovementController
   - ImportReceiptController
   - CouponController
   - RoleController
   - PermissionController
   - UserAddressController

7. CÁC SERVICES (LỚNG ỨNG DỤNG)
================================================================================

1. AuthService
   - Xác thực người dùng (login)
   - Tạo JWT token
   - Xác minh OTP
   - Xử lý Google OAuth
   - Quản lý refresh token

2. UserService
   - Đăng ký người dùng mới
   - Lấy thông tin người dùng
   - Cập nhật profile
   - Quản lý vai trò người dùng
   - Quản lý quyền hạn

3. BookService
   - Lấy danh sách sách với phân trang
   - Tìm kiếm sách
   - Lấy chi tiết sách
   - Quản lý danh mục, tác giả, nhà xuất bản
   - Tính toán rating

4. CartService
   - Tạo/lấy giỏ hàng
   - Thêm/xóa chi tiết giỏ
   - Cập nhật số lượng
   - Tính tổng tiền
   - Áp dụng mã giảm giá

5. OrderService
   - Tạo đơn hàng từ giỏ hàng
   - Lấy chi tiết đơn hàng
   - Cập nhật trạng thái đơn hàng
   - Hủy đơn hàng
   - Tính toán tiền cuối cùng (sau giảm giá)

6. ReviewService
   - Tạo/cập nhật/xóa đánh giá
   - Tính rating trung bình sách
   - Kiểm tra người dùng đã review chưa

7. NotificationService
   - Gửi email xác thực OTP
   - Gửi email xác nhận đơn hàng
   - Gửi email thông báo
   - Gửi email đặt lại mật khẩu

8. OtpService
   - Tạo OTP ngẫu nhiên
   - Xác minh OTP
   - Quản lý hạn giới gửi lại OTP
   - Xóa OTP hết hạn

9. CouponService
   - Xác thực mã giảm giá
   - Tính toán số tiền giảm
   - Kiểm tra thời hạn sử dụng
   - Kiểm tra giới hạn lần sử dụng

10. StockService/StockMovementService
    - Quản lý tồn kho
    - Tạo chuyển động tồn kho
    - Nhập hàng từ nhà cung cấp
    - Kiểm tra hàng tồn kho

11. SupplierService
    - Quản lý nhà cung cấp
    - Lấy danh sách nhà cung cấp
    - Cập nhật thông tin nhà cung cấp

12. RoleService & PermissionService
    - Quản lý vai trò
    - Quản lý quyền hạn
    - Gán quyền cho vai trò

13. UserAddressService
    - Quản lý địa chỉ người dùng
    - Đặt địa chỉ mặc định

13. BẢO MẬT & XÁC THỰC
================================================================================

JWT AUTHENTICATION:
- Token format: Bearer <token>
- Token expiration: 60 phút
- Refresh token expiration: 30 ngày
- Lưu trữ: Authorization header

BCRYPT PASSWORD:
- Hash mật khẩu với Bcrypt
- Salt ngẫu nhiên tự động
- So sánh an toàn

OAUTH2 / GOOGLE LOGIN:
- Google Client ID configuration
- OAuth2 Resource Server setup
- Social login integration

ROLE-BASED ACCESS CONTROL (RBAC):
- Roles: ADMIN, USER, SUPPLIER
- Permissions: gán cho từng role
- @PreAuthorize annotation cho checking quyền

CORS:
- Allowed origins: localhost:5173, 127.0.0.1:5173 (configurable)
- Cho phép frontend gửi request

15. DESIGN PATTERNS ĐƯỢC SỬ DỤNG
================================================================================

1. REPOSITORY PATTERN: Trừu tượng hóa data access
2. SERVICE LAYER: Đóng gói business logic
3. COMMAND PATTERN: Đại diện cho ý định người dùng
4. DTO PATTERN: Tách domain models khỏi API contracts
5. ASSEMBLER PATTERN: Chuyển đổi giữa domain objects và DTOs
6. STRATEGY PATTERN: Email service implementations
7. FACTORY PATTERN: Tạo objects như Order, User
8. DEPENDENCY INJECTION: Spring DI container
9. OBSERVER PATTERN: Spring Events cho loose coupling
10. SPECIFICATION PATTERN: Complex query logic

17. CÁC CONVENTION & NAMING

CLASS NAMES:
- Controllers: *Controller (UserController, BookController)
- Services: *Service (UserService, OrderService)
- Repositories: *Repository, *JpaRepository
- Commands: *Command (CreateUserCommand)
- DTOs: *Request, *Response (CreateUserRequest, UserResponse)
- Entities: Domain entities (User, Book, Order)

METHOD NAMES:
- Get single: get*ById, find*ById
- Get list: get*All, find*All
- Create: create*, save*
- Update: update*, modify*
- Delete: delete*, remove*
- Check: is*, has*

CONSTANTS:
- All uppercase with underscore: DEFAULT_PAGE_SIZE, MAX_RETRIES

PACKAGES:
- Lowercase with dot: com.bookstore.bookstore.application.service

18. TROUBLESHOOTING
================================================================================

ISSUE: Port 3306 already in use
FIX: Kill process or use different port
  netstat -ano | findstr :3306
  taskkill /PID <PID> /F

ISSUE: JWT token expired
FIX: Gọi /api/auth/refresh-token để lấy token mới

ISSUE: CORS errors
FIX: Kiểm tra CORS_ALLOWED_ORIGINS trong application.yml

ISSUE: Database connection failed
FIX: 
  - Kiểm tra MySQL đang chạy: docker-compose ps
  - Kiểm tra credentials trong .env
  - Kiểm tra database tồn tại

ISSUE: Test failures
FIX: Chạy với verbose mode: mvn test -X

TỔNG KẾT
================================================================================

Bookstore Backend là một ứng dụng Spring Boot chuyên nghiệp, sử dụng Domain-Driven
Design, được xây dựng để quản lý một nền tảng bán sách trực tuyến hoàn chỉnh.

Với kiến trúc lớp sạch, tách biệt rõ ràng các layer (Presentation, Application,
Domain, Infrastructure), dự án dễ dàng bảo trì, mở rộng và test.

Công nghệ hiện đại (Java 21, Spring Boot 3.5.14, MySQL 8.0, JWT, OAuth2, Docker)
đảm bảo dự án có khả năng mở rộng và bảo mật cao.

Tất cả các tính năng e-commerce cần thiết đều được triển khai:
- Quản lý người dùng & xác thực
- Danh mục sách & tìm kiếm
- Giỏ hàng & đặt hàng
- Hệ thống đánh giá
- Mã giảm giá
- Quản lý tồn kho
- Thông báo email

Dự án sẵn sàng để phát triển thêm các tính năng cao cấp hơn như thanh toán trực tuyến,
công cụ gợi ý, và xây dựng cơ sở hạ tầng microservices trong tương lai.
